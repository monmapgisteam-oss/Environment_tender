# Гүйцэтгэлийн хянагч

Гэрээт ажлын үе шатны хугацааг хянаж, **шатлан мэдээллэх** (escalation) мэдэгдлийг автоматаар
үүсгэдэг систем. Нийслэлийн Байгаль Орчны Газрын 20 гүйцэтгэгч компанийн ажлыг нэг дор хянана.

**Ажиллаж буй хувилбар:** https://monmapgisteam-oss.github.io/Environment_tender/

Өгөгдлийн эх сурвалж: `БАЙГАЛЬ ОРЧНЫ ХЯНАЛТЫН НЭГДСЭН СИСТЕМ — ТӨЛӨВЛӨГӨӨ (2026.06.15)`,
гэрээ **НХААГ/20260102029** ("Монмэп" ХХК).

## Үндсэн зарчим

Ажлын үе шат бүрийн эцсийн хугацааг **Х** гэвэл:

| Шат | Хэзээ | Хэн рүү |
|---|---|---|
| 1. Урьдчилсан сануулга | Х − 14 хоног | Гүйцэтгэгч компанийн төслийн менежер |
| 2. Эцсийн сануулга | Х − 3 хоног | Гүйцэтгэгч компани |
| 3. Хугацаа хэтэрсэн | Х + 1 хоног | **+ Захиалагчийн холбогдох хэлтсийн дарга** |
| 4. Ноцтой хоцролт | Х + 7 хоног | **+ Газрын дарга, гүйцэтгэгчийн гүйцэтгэх захирал** |

Хугацаа дуусахаас өмнө тайлан ирсэн бол дараагийн шатны мэдэгдэл үүсэхгүй. Хоногийн тоог
`/tohirgoo` хуудсаас өөрчилнө. Мэдэгдэл амралтын өдөрт таарвал өмнөх ажлын өдөр рүү шилжинэ.

## Хамрах хүрээ

- **20 гүйцэтгэгч компани**, нийт **169 ажил**, **763 хяналтын цэг**
- 1 дүгээрт "Монмэп" ХХК-ийн бодит төлөвлөгөө (87 ажил × 5 үе шат), 2-20 дугаарт байгаль орчны
  чиглэлийн бусад гэрээт ажлууд (агаарын чанар, ойжуулалт, усны шинжилгээ, хөрсний бохирдол,
  хүлэмжийн хий, био олон янз байдал, нөхөн сэргээлт г.м.)
- Компани бүр өөрийн гэрээний хугацаа, үе шаттай; захиалагч талаас хариуцах хэлтэс харгалзана
- Өгөгдлийг `lib/plan.ts`-ээс өөрчилнө

## Дэлгэцүүд

| Зам | Агуулга |
|---|---|
| `/` | Хяналтын самбар — анхааруулга, үзүүлэлт, гүйцэтгэлийн муруй (компаниар шүүх), хуанли, анхаарал шаардсан ажил, төлөвийн бүтэц, компаниудын хүснэгт |
| `/ajil` | 763 хяналтын цэгийн жагсаалт: хурдан шүүлтүүр, компани/хэлтсээр шүүх, хайлт, CSV татах |
| `/medegdel` | Илгээсэн мэдэгдэл — шатлалын тайлбар, шүүлтүүр, хүлээн авагч, албан бичгийн эх бичвэр |
| `/tohirgoo` | Шатлалын хоног, нөхцөл, хэлтсийн дарга нар, компаниудын хариуцагчид |

Компанийн нэр дээр дарахад самбар бүхэлдээ тухайн компаниар шүүгдэнэ. Хуудсыг дахин ачаалахад
"Бүх гүйцэтгэгч" рүү буцна. Дээд мөрний **хяналтын огноо**-г өөрчилж шатлал хэрхэн ажиллахыг
шалгаж болно.

## Хэрхэн ажилладаг вэ

Энэ бол **статик хувилбар** — сервергүйгээр, бүхэлдээ хөтөч дээр ажиллана:

- `lib/plan.ts` + `lib/seed.ts` — төлөвлөгөөг санах ойд тогтмол үүсгэнэ (763 хяналтын цэг)
- `lib/escalation.ts` — дүрмийн хөдөлгүүр: төлөв тооцох, мэдэгдэл үүсгэх
- `lib/store.ts` — хэрэглэгчийн өөрчлөлтийг `localStorage`-д хадгална (тохиргоо, гараар бүртгэсэн
  тайлан). Хуудас ачаалах бүрд хөдөлгүүр дахин ажиллаж мэдэгдлүүд тооцогдоно

Ингэснээр GitHub Pages дээр төлбөргүй, сервергүй ажиллана. **Хязгаар:** өгөгдөл хэрэглэгч бүрийн
хөтөч дотор тусдаа хадгалагдана, и-мэйл автоматаар илгээхгүй.

Бүх хэрэглэгч нэг нийтлэг өгөгдөлтэй байх, и-мэйл/вебхүкээр мэдэгдэл илгээх шаардлагатай бол
`lib/store.ts`-ийн оронд серверийн өгөгдлийн сан (Postgres, MongoDB) залгаж, өдөр тутам
хөдөлгүүрийг дуудах cron нэмнэ — хөдөлгүүр (`lib/escalation.ts`) өөрчлөгдөхгүй.

## Ажиллуулах

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # статик файлууд out/ хавтаст үүснэ
```

## Байршуулалт

`main` салбар руу push хийх бүрд [GitHub Actions](../.github/workflows/deploy.yml) ажиллаж,
`npm run lint` → `npm run build` (PAGES=1) → GitHub Pages руу автоматаар байршуулна.

Repository → Settings → Pages → **Source: GitHub Actions** гэж нэг удаа тохируулна.

Өөр газар байршуулах бол `out/` хавтасны агуулгыг ямар ч статик хостинг (Netlify, дотоод
вэб сервер, IIS) руу хуулахад хангалттай. Дэд зам хэрэггүй бол `PAGES` хувьсагчгүй build хийнэ.

## Дизайн

Харанхуй ба гэрэл горим (дээд мөрний товчоор солино, сонголт хөтөчид хадгалагдана). Дарууссан
өнгө: ганц өргөлт өнгө (номин цэнхэр), төлөвийн гурван өнгө — хөх ногоон (гүйцэтгэсэн), охра
(сануулга), тоосгон улаан (хугацаа хэтэрсэн). 1280px-ээс өргөн дэлгэцэд самбар бүхэлдээ нэг
дэлгэцэд багтана. Фонт: Unbounded / Manrope / JetBrains Mono. График бүр гадаад сангүй,
SVG-ээр бичигдсэн (`components/charts.tsx`).
