# Environment_tender

Нийслэлийн Байгаль Орчны Газрын **гэрээт ажлын гүйцэтгэлийн хяналтын систем**.

| Хавтас / файл | Агуулга |
|---|---|
| [`hyanalt-system/`](hyanalt-system/) | Next.js програм — хяналтын самбар, ажлын жагсаалт, мэдэгдлийн төв, дүрмийн тохиргоо, шатлан мэдээллэх хөдөлгүүр |
| `БАЙГАЛЬ ОРЧНЫ ХЯНАЛТЫН НЭГДСЭН СИСТЕМ- ТӨЛӨВЛӨГӨӨ санал 20260615.docx` | Эх төлөвлөгөө (НХААГ/20260102029 гэрээ) — системийн өгөгдлийн эх сурвалж |

## Хурдан эхлэх

```bash
cd hyanalt-system
npm install
npm run dev        # http://localhost:3000
```

Дэлгэрэнгүй заавар, дүрмийн тайлбар, байршуулалтыг [hyanalt-system/README.md](hyanalt-system/README.md)-ээс үзнэ үү.
