# Environment_tender

Нийслэлийн Байгаль Орчны Газрын **гэрээт ажлын гүйцэтгэлийн хяналтын систем** — 20 гүйцэтгэгч
компанийн 763 хяналтын цэгийн хугацааг хянаж, шатлан мэдээллэх мэдэгдлийг автоматаар үүсгэнэ.

**Ажиллаж буй хувилбар:** https://monmapgisteam-oss.github.io/Environment_tender/

| Хавтас | Агуулга |
|---|---|
| [`hyanalt-system/`](hyanalt-system/) | Next.js програм (статик хувилбар) — заавар, дүрмийн тайлбар нь дотор нь |
| [`.github/workflows/`](.github/workflows/) | GitHub Pages руу автоматаар байршуулах workflow |

## Хурдан эхлэх

```bash
cd hyanalt-system
npm install
npm run dev        # http://localhost:3000
```

Дэлгэрэнгүй заавар, дүрмийн тайлбар, байршуулалтыг [hyanalt-system/README.md](hyanalt-system/README.md)-ээс үзнэ үү.
